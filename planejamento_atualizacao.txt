1. VISÃO GERAL DA ARQUITETURA ATUAL
================================================================================

Fluxo Original:
1. Download → goGribV2.sh baixa GRIBs do NOAA (GFS 0.25°/1.00°)
2. Leitura → leitura_dados_grib_MET.py (classes leitura_dados_gribs_AUT/MAN)
3. Processamento → processamento_dados_MET.py extrai variáveis por nível/região
4. Geração → gera_mapas_MET.py (PNG) + gera_matriz_MET.py (CSV) + gera_matriz_vento_MET.py

Variáveis Atuais Suportadas:
- Pressão: ps (superfície), prnm (nível do mar)
- Temperatura: temp (isobárico), temps (superfície)
- Nebulosidade: nuvem
- Precipitação: chuvaNaoConvec, chuvaConvec
- Umidade: umidadeRel
- Vento: u, v (isobárico), uSupe, vSupe (altura)

Variáveis de Poluição Disponíveis no GRIB (já presentes nos dados):
- Ozone mixing ratio (já existe em variables.txt)
- Flags: is_chemical, is_aerosol, is_aerosol_optical indicam mais dados químicos/aerossóis

4.2 core/persistence.py - Camada de Persistência (NOVO)
--------------------------------------------------------
SQLite Schema:

CREATE TABLE IF NOT EXISTS grib_metadata (
    id INTEGER PRIMARY KEY,
    file_path TEXT UNIQUE,
    analysis_time TEXT,  -- 00, 06, 12, 18
    forecast_hour INTEGER,
    data_date TEXT,
    resolution TEXT,  -- 0p25, 1p00
    downloaded_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);

CREATE TABLE IF NOT EXISTS processed_data (
    id INTEGER PRIMARY KEY,
    grib_metadata_id INTEGER,
    variable_code TEXT,  -- temp, o3, u, etc.
    level_type TEXT,     -- surface, isobaricInhPa, heightAboveGround
    level_value INTEGER, -- 1000, 850, 10, etc.
    region_code TEXT,    -- SP, RJ, etc.
    min_value REAL,
    max_value REAL,
    mean_value REAL,
    data_json TEXT,      -- Matriz completa em JSON (opcional)
    csv_path TEXT,       -- Caminho do arquivo CSV
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    FOREIGN KEY (grib_metadata_id) REFERENCES grib_metadata(id)
);

CREATE INDEX idx_processed_lookup ON processed_data(variable_code, level_value, region_code, analysis_time);

Funcionalidades:
- save_grib_metadata() - Registra GRIB baixado
- save_processed_data() - Salva resultados processados (SQLite + CSV)
- query_data() - Consultas flexíveis (variável, nível, região, data)
- export_csv() - Exporta consultas para CSV
