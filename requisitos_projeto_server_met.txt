Leia e analise todo o diretório, subdiretório e arquivos. Este é um projeto de um servidor de meteorologia que criei há muito tempo que tinha como fluxo, primeiramente, baixar os dados de grb e metar, depois realizar tratamento e extração de dados e resultados e posteriormente disponibiliza-los. Realize o planejamento para a atualização deste projeto que deve consistir em uma atualização funcional mantendo as características originais do projeto. Adicionei novos requisitos para a atualização também: 

1° - Mantenha a ordem do fluxo no qual inicialmente os dados devem ser baixados, tratados e ter resultados. Depois os dados devem ser disponibilizados.
2º - Explore os arquivos de grb e encontre variáveis de poluição e as inclua no projeto para serem tratadas e gerarem resultados como as demais que já fazem parte do fluxo.
3° - Use as regiões e níveis já definidas no projeto.
4º - Mantenha a linguagem python no projeto. 
5º - Lembre-se que de há um ambiente python criado para este projeto que pode ser ativado em ~/envs/met/bin/activate.   
6° - Adicione como camada de persistencia/armazenamento de dados um banco de dados simples como sqlite e também a geração de arquivos .csv
7º - Adicione um componente de um servidor funcional usando API REST para requisições dos resultados e também um frontend simples para que seja possível visualizar os resultados já existentes criados nas etapas anteriores.
8º - Priorize por uma arquitetura simples, mas também modular para que a atualização do projeto seja leve e leve ao executar. 
9º - Realize testes com dados reais de ponta a ponta, havendo erros realize correções.
10º - Compile todo o planejamento em um arquivo de texto que deve estar neste diretório.
